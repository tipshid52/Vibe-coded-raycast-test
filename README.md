# RayCasting Test

A small 3D graphics experiment made with **C#** and **Raylib-cs**.

Currently features a simple gray 3D cube with black outlines, a rotating camera, and a minimal retro-inspired HUD.

> Vibe coded!! dont assume i made it myself im a beginner // 3D

## Features

- 3D cube rendering
- Black wireframe outlines
- Smooth camera orbit
- Light gray aesthetic
- FPS counter
- Resizable window

## Built With

- C#
- Raylib-cs
- .NET

## Getting Started

### Requirements

- .NET SDK
- Raylib-cs dependencies used by this project

### Run Locally

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd RaycastCubeTest
```

Run the project:

```bash
dotnet restore
dotnet run
```
